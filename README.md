# XDriverLoaderGUI
test Driver LoadDriver Win10-11 without Sign



### Overview

XDriverLoader is a Windows kernel driver loader that allows loading unsigned or test-signed drivers on Windows 10/11 systems. It utilizes vulnerable driver exploitation (BYOVD - Bring Your Own Vulnerable Driver) technique to bypass Driver Signature Enforcement (DSE).
